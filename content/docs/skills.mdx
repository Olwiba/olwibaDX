A skill is a markdown file an agent reads to learn a workflow. It lives in a repository, and
each project that wants one needs its own copy.

The catalogue is hosted on [olwiba.com/skills](https://olwiba.com/skills) and maintained there,
so this page links out rather than restating it. They work with Claude Code, Cursor, AMP,
Windsurf and anything else that reads skill files off disk.

## Installing

[`dx skills install`](/docs/tools/skills) pulls them into the current project. It reads the
published manifest, so you get whatever is current rather than whatever was current when you
last copied files around.

```bash
bunx @olwiba/dx skills install
```

Pick from a list, or take the lot:

```bash
bunx @olwiba/dx skills install --all
bunx @olwiba/dx skills install --name debug,fix-ci
```

Skills land in `.claude/skills/` by default. Pass `--target amp` for `.amp/skills/`.

## Writing your own

A skill is a markdown file with frontmatter naming it and saying when to use it. Nothing about
the format is olwiba-specific. The manifest is public JSON and the install command takes a
`--source` URL, so you can host your own catalogue without asking anyone.
