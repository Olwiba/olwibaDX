Small tools that run in a browser tab. No sign-up, nothing sent to a server.

Most of them live on [olwiba.com/toolbox](https://olwiba.com/toolbox). They are not part of
`@olwiba/dx` and there is nothing to install: open the page and use it.

## On olwiba.com

| Tool | For |
| --- | --- |
| [JSON Formatter](https://olwiba.com/toolbox/json-formatter) | Formatting and validating JSON |
| [RegEx Tester](https://olwiba.com/toolbox/regex-tester) | Building a pattern against sample text |
| [JWT Debugger](https://olwiba.com/toolbox/jwt-debug) | Reading what is actually in a token |
| [Text Comparer](https://olwiba.com/toolbox/text-comparer) | Diffing two blocks of text |
| [Cron Parser](https://olwiba.com/toolbox/cron-parser) | Working out when a schedule actually fires |
| [Hash Generator](https://olwiba.com/toolbox/hash-generator) | MD5, SHA and friends |
| [Checksum Generator](https://olwiba.com/toolbox/checksum-generator) | Verifying a file has not changed |
| [Base64 Encoder](https://olwiba.com/toolbox/base-64-encoder) | Encoding and decoding Base64 |
| [URL Encoder](https://olwiba.com/toolbox/url-encoder) | Percent-encoding query strings |
| [HTML Encoder](https://olwiba.com/toolbox/html-encoder) | Escaping markup for safe output |
| [UUID Generator](https://olwiba.com/toolbox/uuid-generator) | Generating v4 identifiers |
| [Color Picker](https://olwiba.com/toolbox/color-picker) | Picking and converting colours |
| [Timestamp Converter](https://olwiba.com/toolbox/timestamp-converter) | Unix time to something readable |
| [Timezone Converter](https://olwiba.com/toolbox/timezone-converter) | What time it is somewhere else |
| [Kanban](https://olwiba.com/toolbox/kanban) | A board, with no account attached |
| [Idea Mapper](https://olwiba.com/toolbox/idea-mapper) | Getting a tangle of thoughts onto a canvas |
| [Kiwipsum Generator](https://olwiba.com/toolbox/kiwipsum-generator) | Placeholder text, with an accent |

That list moves as tools get added. [Browse the current one](https://olwiba.com/toolbox).
